# Design Docs

Working notes and design proposals that haven't (yet) been distilled into a
backlog item or an authority doc under `docs/`. Use this folder for:

- Rough design sketches / brainstorms before they're ready for `backlog.json`.
- Longer-form design rationale that doesn't belong in a single item's `design`
  field.

One file per topic. When a doc's content graduates into a backlog item or a
subject authority doc, either delete the file or leave a one-line pointer at
the top noting where it landed.

## Authorship

Backlog items in `docs/development/backlog.json` may carry an `"author"`
field (e.g. `"author": "Joe"`) identifying who proposed the item. This is
informational only — it does not affect status, priority, or workflow.
